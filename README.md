## Description
Application d'analyse de données sportives supportant 9 sports : football, basketball, tennis, volleyball, chess, badminton, StarCraft 2, League of Legends, Counter-Strike 2.

## Version Python
Python 3.13

## Installation

### Installer les dépendances
Pour installer les dépendances, il faut entrer la commande suivante dans le terminal : 
pip install -r requirements.txt


## Lancer l'application
Entrer la commande suivante pour lancer l'application
python __main__.py


## Tests
Pour effectuer les tests, entrer la commande suivante dans le terminal
python -m pytest --cov


## Linter
Nous utilisons Ruff comme Linter, saisir la commande suivante
ruff check src/


## Documentation
Les docstrings sont de style NumPy
